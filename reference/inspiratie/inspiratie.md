# Inspirație Bolders

Surse: maxim 2. Identitatea (logo, culori, fonturi, texte) rămâne Bolders.
Evităm tot ce e Three.js / WebGL.

## 01-hero

Link: https://bolders1.webflow.io/
Sursă: hero-ul actual Bolders (nu studiors)
Ce preiau: structura, textele și animația cu literele din hero-ul actual
Ce modernizez: intrarea literelor mai fluidă (cu mască, nu doar apariție), tipografie mai mare, ritm mai bun pe mobil
Ce NU preiau: rămășițele de template din cod, nimic din hero-ul studiors
Unde la noi: hero homepage
Fișier: hero.png
